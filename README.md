# Biblioteks-AI

An interactive evaluation tool for Nordic librarians navigating AI in cataloguing workflows.

**Biblioteks-AI** helps library staff assess and compare AI tools by task type, language support, cost, and maturity level — with a specific focus on Nordic library contexts, Swedish-language cataloguing, and integration with systems such as Libris XL and Koha.

---

## What it does

- **Tool comparison** — filter and compare AI tools across cataloguing tasks: subject indexing, authority control, classification, description generation, and quality review
- **Evaluation rubric** — structured criteria for assessing AI tool maturity and fit for library workflows
- **Nordic landscape overview** — coverage of KB-BERT, KB-Whisper, KBLab projects, and Annif, with notes on Swedish-language and multilingual data handling
- **GDPR and data governance notes** — flags tools and configurations relevant to Swedish and EU data protection requirements

---

## Who this is for

- Cataloguers and metadata librarians at Nordic public, research, and special libraries
- Library management evaluating AI tool adoption
- LIS educators and students studying AI in cataloguing
- Developers building or integrating AI tools into library systems

---

## Stack

- React 18 + Vite 6
- Tailwind CSS 3
- No backend — runs entirely in the browser

---

## Development

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # production build to dist/
npm run preview  # preview the production build
```
